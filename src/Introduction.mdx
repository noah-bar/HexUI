# HexUI

Hex-Tech's React component library, built on **Base UI** (behavior & accessibility)
and **Tailwind CSS v4** (styling), with a visual signature: **professional glassmorphism**.

## Glass principles

- **Readability first**: surfaces stay 70–85% opaque, and blur serves depth, not decoration.
- **Six levels**:
  - `glass-thin`: navigation, toolbars, tabs (little text);
  - `glass`: cards, panels;
  - `glass-strong`: menus, tooltips;
  - `glass-dialog`: dialogs and toasts, more transparent but heavily blurred;
  - `glass-field`: form fields;
  - `glass-tint`: tinted glass for actions (primary and danger buttons, checked switch), filled at 85% minimum
    so white text stays readable.
- **A real material**: lit edge at the top left, a light sheen at the top, a very fine frosted-glass grain.
  No element is a flat opaque fill, and there is no glow.
- **Hover and selection**: *inside* a glass surface (rows, list items, ghost button), use a light
  `tint-hover` / `tint-active` veil. *On* a glass element (secondary button), use `glass-hover`.
  A selected element sitting on glass (tab indicator) is always lighter than its container.
- **Accessible fallbacks**: surfaces become opaque automatically when the browser does not support `backdrop-filter`,
  when the user turns on "Reduce transparency", or in high-contrast mode.

## Background

The `Backdrop` component provides the background that gives glass its meaning. Change it from the **Background**
tool in the toolbar to check that a component stays readable on each variant, including with no background.

## Themes

Add the `dark` class (or `data-theme="dark"`) to `<html>`. Use the Storybook toolbar to switch.

## Customization

The palette is indigo (`#4f46e5`) on neutral grays. The background glows combine indigo, cyan and light violet.

Every color is an overridable `--hx-*` CSS variable:

```css
:root {
  --hx-accent: #a5b4fc;
  --hx-glass-blur: 12px;
}
```
